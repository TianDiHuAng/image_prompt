## 技法详解

### T1 · "女性写真生成助手"总模板的可取与可改
- 可取:参数化选择(写真风格/场景/服装/气质/镜头/画幅)、"第一眼吸睛点"、姿态要有重心变化(避免僵硬)、"性感只表现为高级克制"。
- 要改:反复强调胸部、胸腰关系、S型曲线的**部位罗列**;本skill改用"廓形语言":沙漏廓形、腰线清晰、肩颈线、腿部比例。
- 可借用的参数表见 `prompt-templates.md` 的"参数化总模板"。

### T2 · 完整范本拆解(#2)
结构:`画幅+拍摄方式` → `拍摄者位置/机位` → `人物(年龄/长相/素颜细节/瑕疵)` → `辨识点` → `身材(廓形语言)` → `服装(穿法)` → `腿(焦点)` → `动作` → `光线(冷暖)` → `环境(叙事小物)` → `质感(设备痕迹)`。
可迁移:任何场景都能套这 11 段。

### T3 · 随机池(#4、#19)
```
固定视觉DNA:[画幅]、[成年人设]、[拍摄方式]、[真实感关键词]
场景[…/…/…]  事件[…]  神态[…]  造型[…]  前景[…]  配色[…]
规则:每次只抽一项;不继承上一张;单图,禁止拼图/多宫格
```
COS 角色池:每次只选一个角色,不混合外貌;统一"明确成年真人COS";服装"现代生活化改造"(保留配色与少量标志元素,融入针织衫/运动外套/卫衣)。

### T4 · 模块式(#6、7、13、17、21、25b、26)
```
主题:一句话事件
主体:成年女性、年龄段、整体姿态/身体走向
人物·表情:脸型、眼睛、唇色、发型、肤色、光对脸的影响
服装·姿势:衣服+手脚怎么放
背景·光线:前景/中景/远景物件 + 光源
构图·镜头:画幅、机位、人物占比、裁切
质感·风格:色调、材质对比、整体气质
```
特点:每一段 1–3 句,极少形容词,多为位置与形状。容易稳定复现。

### T5 · 锁定式(#18)
```
【锁定·不改变】PRESERVE — 人数、发型发色、关键配饰、服装关键细节、姿势、环境、媒介
CONSTRAINTS — 人数肢体数量;必须可见的接触点;表情限制;颜色锁定;绝对禁止项
【TONE】光线/色调/焦点/第一视觉重点与第二重点
```
用于:多次迭代同一角色、插画、防止模型"自作主张改衣服"。

### T6 · 古装/新中式(#14、15、27)
- 古装:唐风齐胸襦裙→裙头(米白绣花宽边)、茶金长带(围一圈麻花结,两端自胸口垂下)、粉色多层纱裙、米白薄纱大袖衫(袖边茶橙渐变)。**每个配件写"来历与走向"**。
- 新中式:黑色蕾丝改良旗袍短裙、高领、盘扣、黑色花卉蕾丝长袖拼接、胸前不透明内衬、花边收口、大腿袜(蕾丝顶部)、漆皮高跟(暗红鞋底)。
- 水乡:淡藕粉真丝上衣、湿润黑发、雨后荷叶与木窗框、iPhone感。

## 技法拆解(提炼,不照抄)

### T10 · 水下双拼(#29)
结构 = **「全景氛围层 + 局部特写层」双画面拼接**。技法:焦散光斑(caustics)与青绿/淡粉环境色反射到暖白肤;湿纱遇水贴合→半透明褶皱、边缘漂散;情绪用"眼睛半闭/唇微张带水光/欲言又止";顶部自然散射光穿水面→斑驳光晕。
关键新点 = **区域选择性清晰**:只保护"下半部分侧脸"清晰,身体与衣料被水波柔化——把"哪里清晰"写死,别整张糊或整张锐。可迁移到泳池/水汽/浴室题材。

### T11 · 古风胶片仕女(#30)
在既有古装/新中式(见 T6)之上补:①**仰视机位 + 仕女感**;②**前景模糊花瓣虚化框**;③超长复古耳坠、战国袍、花树作道具叙事;④明暗交接 + 暗朦/lomo 的胶片氛围;⑤9:16 竖幅。技法可复用,古装细节继续沿用 T6。

### T12 · 暗黑浪漫泛影(#31)
配方:大面积高曝负空间(留白) + 超广角强透视延伸 + 灰青褪色胶片粗颗粒 + 逆朦/泛影/耀光 + 粒子高噪点 + 暗黑浪漫。
**注意**:原提示词接近"50 词堆叠"的反面教材(对照 T9/#11)。正确做法=收敛到"负空间 + 超广角 + 褪色粗颗粒"三个一致风格词 + 明确光位,不照抄整串。
