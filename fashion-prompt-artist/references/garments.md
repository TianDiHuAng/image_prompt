## 针织类

### 针织开衫 Cardigan(重点)
**写法公式**:`[长度] + [针法/厚度] + [扣法/领型] + [穿法] + [内搭]`

| 维度 | 词汇 |
|---|---|
| 长度 | 超短(cropped,露腰)/ 常规 / 过臀 / 及膝长款 / 茧型超大 |
| 针法 | 麻花(cable-knit)/ 罗纹(ribbed)/ 华夫格 / 蓬松马海毛(mohair fuzzy)/ 细羊绒 / 粗粒毛线 / 镂空钩花 / 网眼 / 渐变段染 |
| 领型 | V领 / 圆领 / 无领 / 披肩领 / 立领 / 翻领 |
| 扣法 | 单排珍珠扣 / 金属扣 / 木扣 / 单扣系一颗 / 不系 / 腰带系带 |
| 穿法 | **半扣(只系中间一颗)**、**错位扣**、**滑落露肩**、**反穿**、**披在肩上**、**当上衣只扣两颗露内搭**、**短开衫+高腰裙** |
| 内搭 | 丝缎吊带 / 蕾丝吊带 / 白色背心 / 衬衫 / 无肩带内衣式上衣(要写明"有内搭") |

**氛围示例**
- *慵懒温柔*:奶白色蓬松马海毛短开衫,只系一颗珍珠扣,微微滑落一侧肩,露出缎面吊带的细肩带与锁骨;下配低腰灰色羊毛长裙。
- *知性克制*:燕麦色细羊绒长开衫,V领,腰带松松系着,内搭黑色真丝吊带与长项链。
- *Miu Miu式俏皮(成年)*:粉色超短针织开衫,小圆领,金色小扣,下搭低腰迷你褶裙与白色短袜、玛丽珍鞋。
- *Balenciaga式*:炭灰色超大粗针开衫,肩线下坠,袖长盖过手背,内搭贴身黑色罗纹吊带裙。

### 其他针织
- 毛衣:套头 / 高领(turtleneck)/ 半高领 / 船领 / 露肩 / 斜肩 / 一字领 / 镂空 / 罗纹紧身
- 针织连衣裙:紧身(Alaïa式)、长款包臀、侧开衩、露背
- 针织背心 / 针织吊带 / 针织三件套(cardigan + camisole + skirt)
- 针织配件:长围巾、针织手套、针织袜套、针织发带

## 连衣裙与裙装
- **晚礼服**:拖尾、鱼尾、A字、茧型、美人鱼、抹胸、吊带、挂脖、不对称单肩
- **小黑裙**:H型直筒、收腰A字、紧身铅笔裙
- **日常**:衬衫裙、针织裙、吊带缎面裙、斜裁裙(bias cut)
- **半裙**:铅笔裙、百褶、伞裙、纱裙、褶皱、不对称、鱼尾、高腰长裙、皮裙
- **长度**:超短 / 膝上 / 及膝 / 中长 / 及踝 / 拖地

## 上装
- 衬衫:真丝、半透、领口深开、不对称、系带、打结露腰
- 吊带 / 背心 / 抹胸 / 挂脖(halter)/ 紧身束衣(corset top)/ bustier
- 蕾丝内衣式上衣(lingerie-inspired top,作为外穿)
- T恤:紧身、超大、露脐、做旧
- 针织 / 皮革 / 缎面短上衣

## 外套
- 西装:强肩(power shoulder)、双排扣、吸烟装、长款 oversized、收腰
- 大衣:驼色羊绒长大衣、茧型、双面呢、腰带款
- 皮衣:机车、短款、长款风衣皮、哑光、漆皮
- 风衣(trench):收腰,立领,腰带
- 披肩 / 斗篷 / 毛皮(仿皮草 faux fur)
- 羽绒:亮面超大

## 下装
- 阔腿裤、西装裤、喇叭裤(低腰)、皮裤、紧身裤、工装裤、短裤、热裤、百慕大裤
- 牛仔:低腰、直筒、阔腿、做旧水洗

## 内搭与衬层
- 蕾丝吊带 / 缎面 camisole / 紧身背心 / 薄纱内衬 / 丝袜 / 网袜 / 吊袜带(装饰性,外搭长裙开衩时隐约可见)
- 原则:透叠永远要有**内衬或内搭**,写出"半透薄纱叠穿于不透明缎面衬裙之上"

## 领型
一字领、V领、深V、方领、心形领、抹胸领、挂脖、高领、船领、吊带、斜肩、单肩、翻领、立领、水手领、蝴蝶结领

## 袖型
无袖、吊带、短袖、泡泡袖、羊腿袖(gigot)、蝙蝠袖、落肩、喇叭袖、盖手袖、可拆袖、手套袖、纱袖

## 下摆与开口
高开衩、侧开衩、前开衩、不对称下摆、拖尾、荷叶边、褶皱、毛边、流苏、鱼尾

# v2 补充品类

## 针织毛衣裙 / 超大毛衣当裙穿
`燕麦白超大号粗棒针毛衣,当毛衣裙穿,下摆刚盖到大腿上段;领口太大,一侧滑下,露出锁骨与一侧肩膀` + 黑色过膝厚棉袜(袜口勒出浅浅软肉)

## 毛绒 / 敞开式开衫
`象牙白长毛绒开衫,自然滑落至上臂,露出肩部与锁骨;内搭奶油白细肩带蕾丝居家短裙`(明确"服装完整覆盖")
`白色蓬松毛衣衣襟敞开,内搭白色花卉蕾丝上衣`

## 丝袜 / 袜类(写D数)
| 类型 | 写法 |
|---|---|
| 超薄透肤 | 15D黑色超薄透肤连裤丝袜,均匀烟黑,细腻丝光 |
| 微透 | 20–30D |
| 烟灰 | 40D烟灰色连裤丝袜,织物细密柔软 |
| 厚灰 | 厚灰色连裤丝袜,偏冷烟灰,冬日感(不透明) |
| 大腿袜 | 烟灰黑超薄大腿袜,顶部精致蕾丝边缘 |
| 过膝袜 | 黑色过膝厚棉袜,袜口勒出浅浅软肉 |
| 短袜 | 白色短袜+玛丽珍 |
要点:写"完整覆盖双腿并连续覆盖足部"防止袜子"断层"。

## 新中式 / 旗袍 / 古装
- 改良旗袍短裙:高领、盘扣、黑色花卉蕾丝长袖拼接、胸前不透明内衬、花边收口
- 唐风齐胸襦裙:米白绣花宽边裙头、茶金长带、粉色多层纱裙、米白薄纱大袖衫
- 淡藕粉真丝中式上衣、浅色中式服装
- 配套:珍珠垂坠耳环、发髻+簪花、油纸伞、团扇

## 睡裙 / 居家
- 雾粉色超薄真丝混纺吊带睡袍连身裙,内敛深V领
- 白色丝绸混纺吊带睡裙,细肩带,贴合身体自然走势
- 奶油白细肩带蕾丝居家短裙 + 毛绒开衫
- 宽松奶油白针织上衣 + 黑色居家短裙 + 40D烟灰连裤袜

## 蕾丝 / 内衣风(作为服装品类,需完整覆盖)
- 酒红波尔多色重工镂空蕾丝套装(editorial/目录级),深V剪裁、黑边花瓣蕾丝滚边;焦点放在**蝴蝶骨与背部绑带**与烛光暗色调
- 黑色蕾丝深V短款上衣,**胸部完整遮挡**,露出腰腹
- 胸衣式上衣(bra top):厚实不透明面料,完整包覆
- 外穿原则:用"完整包覆/不透明内衬/完整覆盖"措辞

## 泳装 / 度假
- 三角比基尼:小锯齿图案(粉蓝黄绿黑)、黑色细绳、腰部系带
- 白色细绳褶边比基尼上装 + 白到浅灰宽松裤,深蓝侧边线,白色系带
- 银色细绳比基尼(水下梦幻)+ 透明厚底平台鞋
- 配饰:玳瑁太阳镜、小花耳饰、细双层项链

## 职业装 / 都市
- 黑色短款修身西装,衣襟敞开,翻领挺括
- 深V胸衣式上衣(不透明)+ 超短高腰包臀职业裙(不走光)+ 15D黑丝 + 尖头细跟
- 修身白色针织上衣微低领 + 黑色高腰包臀短裙 + 烟灰连裤袜 + 黑色尖头高跟
- 便利店制服:修身白衬衫、深色制服马甲、短款包臀制服裙(完整覆盖)、胸牌/围裙

## 礼服 / 背影
- 香槟银细肩带礼服,花纹珠饰与细碎亮片,背部深V开口至腰下附近;低松发髻,珍珠状发饰,细长耳坠
- 酒红真丝长裙背部深U;黑色蕾丝高领礼服

## 衬衫 / 吧台氛围
- 米白色真丝衬衫,领口松开两颗扣,袖口半卷;可搭黑色短裙或深色高腰长裤

## 休闲运动 / 街头
- 宽松连帽卫衣、短款针织开衫、运动夹克、浅色衬衫
- 白色罗纹短款背心 + 黑色短款下装 + 白色风衣夹克(从肩滑落)+ 黑色及膝袜 + 厚底系带靴(搭扣)

# v3 补充:造型策略(来自实测)

## A. 按"露肤区"设计,一套只选一个区
| 露肤区 | 效果 | 句式 |
|---|---|---|
| **背** ⭐性价比最高 | 性感但不越界 | 正面完整覆盖躯干,背部从肩胛开到腰线,只用两条细带横过 |
| 肩颈 | 优雅 | 一字肩长裙,肩线与锁骨完全裸露,领口在胸口上缘 |
| 腰腹 | 年轻利落 | 短款上衣,衣长到肋骨下方,露出整段腰腹 |
| 腿 | 有张力 | 高开衩从脚踝开到大腿中上部(不要开到根部) |
| 深V | 要写"边缘平整"才不跑偏 | 深V领口开到胸口中段,领口边缘平整,完整包覆 |

## B. "将落未落" > "减少布料"
叠穿比单穿耐看。可用句式:
- 白衬衫敞开当外套 + 黑色细吊带
- 薄开衫松垮滑落到手肘
- 白衬衫半褪到肩头,只挂在一边手臂上
- 浴袍前襟交叠、腰带松懈(完整覆盖)
- 毛衣领口滑落一肩,露出吊带细肩带与锁骨

## C. 版型必须写死
不写版型,模型默认给宽松款,显臃肿。
**显身材的句式**:弹力贴身,顺着肩、胸、腰的曲线走,腰线收窄,布料贴着身体,抬手或转身时出现细密横向褶纹
**避免项**:宽松肥大、oversized、臃肿、硬挺版型
(想要慵懒感时反过来:明确写 oversized,并写"下摆盖到大腿上段、袖子盖住手背")

## D. 鞋与腿的必填项
| 要素 | 必须写清 |
|---|---|
| 跟高 | 9cm / 7cm / 5cm / 平底(**不写=默认5cm中跟,气质平庸**) |
| 鞋头 | 尖头 / 圆头 / 方头 |
| 跟型 | 细跟 / 粗跟 / 方跟 |
| 材质 | 哑光牛皮 / 漆皮 / 金属 / 麂皮 |
| 丝袜 | D数 + 袜口(平整/蕾丝宽边/到大腿中部)+ **要有真实织纹与光泽,不要画成塑料管状** |
**构图**:镜头在腰部高度、略低角度、全身到脚踝,腿才显长。

## E. 深色缎面的用法
酒红、墨绿、藏蓝、深紫的缎面或丝绒:反光变成"情调光"。浅色缎面(象牙白、银灰、玫瑰粉)易出塑料感,慎用,必要时写"表面有自然折痕,无油亮高光"。
