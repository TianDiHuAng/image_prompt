# 人物脸型 / 气质 / 风格 / 动物感 分类库

> 用途:给"人物气质"和"长相风格"定性,再**从标签翻译成可见的结构词**写进提示词。
> 铁律:标签只是**选型**,正文必须落到骨相/五官/妆发/光线/神态的具体描写(呼应 SKILL 核心理念①"具体胜过形容词"、`anti-ai-realism.md` 第2节"脸与骨相写结构")。
> 用法:**1 个主类 + 1 个辅类**就够,动物感只做点睛;禁止四组各抓一堆标签堆砌(会互相打架,见 `case-studies.md` T9 / #11)。

## 0. 四条使用规则
1. 先定"主气质"(浓/淡、清冷/氧气…),再选"风格取向"(港风/法式/新中式…),动物感只作点睛。
2. 每个标签必须翻译成 2–3 个可见细节(骨相/五官比例/眉形/眼型/唇/发型/妆感/光线/神态),否则等于没写。
3. **成年锚点永远优先**:所有"显小/童颜/甜"的方向,只描述成年人的骨相(圆脸、短中庭、软组织多),并写明"明确成年的 XX 岁";**不用"幼态/萝莉/学生/少女感"**(安全边界,见 SKILL.md)。
4. 长相风格 ≠ 换脸;同一角色跨图一致时,用锁定式(见 `case-studies.md` T5)+ 固定骨相词。

## 1. 按五官与轮廓(脸型底子)

| 分类 | 一眼特征 | 写进提示词的结构词(示例) | 适合 / 慎用 |
|---|---|---|---|
| 浓颜系 | 五官量大、立体、对比强、量感重 | 眉骨立体、眼裂大而深、鼻梁高挺、唇形饱满、面部折叠度高、明暗对比强 | 明艳/大气/封面;避免小清新弱对比场景 |
| 淡颜系 | 五官秀气、留白多、柔和、对比低 | 眼型细长、鼻背秀气、唇薄而清、面部留白充足、轮廓柔和、低对比柔光 | 干净/耐看/文艺;避免重妆浓对比 |
| 娃娃脸(童颜) | 圆脸、短中庭、下颌圆、软组织多、眼位偏低 | 圆润脸型、中庭偏短、苹果肌饱满、下巴圆钝、眼距略宽、肤质软润 + **必须成年锚点** | 甜/亲和;**禁未成年设定** |
| 成熟系 | 骨骼感强、中庭偏长、脸偏长、气场稳 | 骨相清晰、颧骨与下颌线明显、中庭偏长、下颌角清晰、眼神稳定 | 御姐/权威;避免与幼态混用 |
| 高级脸 | 颧骨/下颌有辨识度、五官不标准但协调、留白多 | 高颧骨、下颌线方中带弧、眼距偏宽、轻微不对称但协调、低表情、冷调 | 时尚大片/杂志;不等于"丑" |
| 建模脸 | 比例精致、对称度高、皮相干净、像 CG | 三庭五眼标准、左右高度对称、皮相细腻、轮廓流畅 | 2.5D/厚涂/虚拟人;**写实慎用**(易塑料感,见 anti-ai-realism) |

## 2. 按气质(情绪底色,决定光与神态)

| 分类 | 气质定位 | 可见写法(光 + 神态 + 造型) |
|---|---|---|
| 清冷系 | 疏离安静不讨好,像雪与月光 | 冷白光/蓝调、少表情、视线越过镜头、唇角平、银灰或黑发、留白背景 |
| 氧气系 | 干净清爽笑明亮,像校园和夏天 | 高调自然光、清透裸妆、露齿笑、马尾/短发、蓝白配色、户外绿意 |
| 森系 | 自然棉麻植物感,安静治愈 | 漫射林间光、麻/棉/针织、低饱和大地色、松散发、绿植前景 |
| 甜妹系 | 柔和亲和可爱,糖分高 | 暖柔光、圆润骨相、笑眼、腮红、柔软针织/碎花 + 成年锚点 |
| 御姐系 | 成熟自信有掌控感 | 硬一边侧光、上扬眼线、红唇或裸棕、西装/包臀、低机位、直视 |
| 知性系 | 书卷气、克制、谈吐稳 | 中性柔光、淡眉、(可选)细框眼镜、素色衬衫/风衣、内扣发、浅笑 |
| 邻家系 | 亲切日常、没有距离感 | 窗边自然光、淡妆、T恤/针织、随手束发、生活场景小物 |
| 氛围感美女 | 五官非顶尖,但光影穿搭神态抓人 | 重点写光比、逆光轮廓光、发丝光、前景遮挡、色调统一(五官少写) |
| 明艳系 | 色彩浓、存在感强,像红玫瑰 | 高饱和红/暖调、浓眉红唇、大波浪、硬光、强对比 |
| 温婉系 | 柔和古典耐看,像水 | 柔光、淡雅色、盘发/低髻、含蓄浅笑、东方留白 |

## 4. 按动物感(神态 / 眼型,只做点睛)

| 分类 | 动物化特征 | 写法 |
|---|---|---|
| 猫系 | 眼尾上扬、慵懒傲娇神秘 | 上扬眼尾、略下垂上睑、半眯、冷淡、尖下巴 |
| 犬系 | 圆眼亲和、忠诚感、笑暖 | 圆而略下垂的眼、卧蚕、露齿笑、软组织 |
| 狐系 | 媚眼聪明妩媚、带攻击性美 | 细长上挑眼、内眼角尖、薄唇微勾、眼神有钩子 |
| 鹿系 | 眼湿润、清纯灵动、易碎感 | 大而湿润的圆眼、长睫毛、无辜抬眸、唇珠 |
| 兔系 | 软萌圆润无害、甜 | 圆脸圆眼、短下巴、腮红、软唇 + 成年锚点 |
| 鲶鱼系 | 眼距宽、唇厚、留白多、时尚高级 | 宽眼距、厚唇、面部扁平留白、低表情、高级感 |
| 鸟系 | 小巧精致、轻盈、精灵感 | 小脸、尖下巴、薄唇、颈细、轻盈体态 |

## 5. 标签 → 正文 的翻译示范(避免"贴标签")

- ❌ 差:"高级脸、清冷系、御姐"(只有标签,模型自由发挥)
- ✅ 好:"高颧骨、下颌线方中带弧、眼距偏宽、低表情;冷白光从左侧压出颧下阴影,唇色裸棕,直视镜头,气场稳"——把 3 个标签落到**骨相 + 光 + 神态 + 妆色**。
- 口诀:**一个标签 = 至少 2 个可见细节**;"浓颜配硬光、淡颜配柔光、清冷去饱和、明艳上暖调"。

## 6. 安全改写(与 SKILL 安全边界一致,强制项)
- "幼态系 / 童颜 / 甜妹 / 兔系 / 纯欲":一律**保留成年骨相描写 + 明确成年的 XX 岁**;**删去"幼态、萝莉、学生、未成年、少女感、纯欲"等直白词**,换成"圆润童颜的成年女性 / 清透克制的成年女性"。
- 动物感只是**神态比喻**,不写"像小动物一样柔弱无助"这类幼化暗示。
- 本文件是**词库/选型库**,不改变既有安全边界与去 AI 感规则。
