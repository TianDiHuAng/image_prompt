## 2. 真实感三件套
**(a) 真实肤质**:毛孔、细小汗毛、眼下阴影、微肿眼皮、鼻头与脸颊自然泛红、**枕头压痕**、酒后微红、唇纹。
**(b) 设备痕迹**:手机噪点、JPEG压缩、轻微运动模糊(窗外电线杆拖影)、局部闪光过曝、背景自然欠曝、轻微倾斜构图。
**(c) 生活瑕疵**:碎发贴脸、头顶睡翘的发丝、衣服褶皱、袖口堆积、袜口软肉压痕、桌上拆开的橘子、对折车票。

## 3. 画质词库
- 手机:`真实iPhone摄影` `前置自拍质感` `轻微手机广角透视` `细微高ISO噪点` `JPEG压缩质感`
- 相机:`RAW照片质感` `85mm f/2` `35mm` `哈苏中画幅胶片` `胶片颗粒` `柔雾低反差`
- 色调:`偏冷蓝灰+局部暖橘` `奶油白高调` `低饱和冷灰` `暖色低照度` `青白色度假阳光`

## 4. 瞬间/事件池(任选其一,让画面有"刚发生")
- 刚醒:趴在铺边探头往下拍 / 枕头压痕 / 睡翘头发 / 捂着保温杯发呆
- 刚进门:单脚脱鞋差点失去平衡 / 抱着购物袋腾不出手 / 外套拉链卡住 / 钥匙掉在地上
- 刚买完:冰淇淋融化滴到手上 / 被海风吹乱头发 / 蹲下捡发圈
- 整理中:提拉丝袜边缘 / 整理头发 / 整理领口
- 微醺:俯身趴吧台、手撑下巴、眼神失焦后望向镜头
- 发呆:坐在窗边、望向窗外
- 休息:拿筷子停顿一下、坐在椅上抱腿、躺在床上抬眼

## 6. 光线配方
- **冷暖交界**:冷白窗光(雪地/阴天)从侧面照脸与锁骨 + 一盏暖黄小灯在头顶或肩头,阴影偏青灰。
- **暖调低照度**:台灯/手机补光落在脸与手背,背景比主体暗约2档,光线不均匀(拒绝影棚均匀光)。
- **窗纱柔焦**:午后阳光透白纱,漫射,轻微风动。
- **逆光轮廓**:伞后/窗后强暖光透穿道具,发缘与肩头一圈暖色轮廓光,面部柔和。
- **CCD直闪**:硬直闪与夏日阳光形成反差,局部过曝。
- **哈苏低调电影光**:烛光/梳妆台微光侧光,低调,面料纹理深邃。

## 7. 避免"AI脸"
正面:`保留轻微不对称` `真实骨相` `自然毛孔` `眼神带倦意` `不刻意微笑`
