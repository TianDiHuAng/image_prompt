## 1. 男性写实的去AI感要点
- **同样适用**:皮肤可以糙、五官不能糙;光写物理现象;手机随手拍三件套;不写"不要X"(无负面口时)。
- **男性特有的AI通病**:皮肤过于光滑如瓷、"偶像脸"、下颌线过锐如刀、胡茬像贴图、肌肉过度夸张、手指过细如女性。
- **对策**:写真实的胡茬分布与密度、毛孔、鼻翼与额头的油光、眉毛的自然杂乱、手背的青筋与指节、不对称的下颌。

## 2. 脸与骨相(写结构,每次换一组)
| 维度 | 词汇 |
|---|---|
| 脸型 | 长脸 / 方圆脸 / 窄长脸 / 圆脸 / 下颌线条自然偏硬朗 / 下颌线柔和 |
| 眉眼 | 浓密略杂乱的眉 / 细长内双眼 / 单眼皮眼梢略垂 / 宽双眼皮 / 眼窝深浅(见偏好开关) |
| 鼻 | 鼻梁中等高度 / 鼻梁挺直 / 鼻头略圆 / 鼻翼自然 |
| 唇 | 唇形平直偏薄 / 唇形饱满 / 唇角自然 |
| 皮肤印记 | 淡淡的雀斑 / 眼下青影 / 一颗小痣 / 细小疤痕(眉尾)/ 毛孔 |
| 胡须 | 干净无须 / 浅青色胡茬(只在下颌与上唇)/ 短而整齐的胡须 / 两天没刮的胡茬 |
**避免写丑**:不写牙齿不齐、塌鼻梁、大面积痘痘,除非用户要求。
(种族/肤色相关写法遵循 `anti-ai-realism.md` 的"可选偏好开关":用户指定才启用,默认不限定。)

## 3. 发型与面部修饰
- **短发**:利落短发、寸头、侧分背头(slicked-back)、碎盖、微卷短发、蓬松刘海
- **中长发**:中分及耳、微卷中长发、低束发、凌乱的发梢
- **长发**:黑色长直发、微卷长发、低马尾
- **质感写法**:发丝带自然油脂光泽、头顶有游离碎发、被雨/雾打湿的发梢、风吹乱的发型
- **修饰**:眉形自然保留、嘴唇略干有唇纹、皮肤有薄油光(不要粉底感)

## 4. 身形(廓形语言,不写部位尺寸)
| 类型 | 写法 |
|---|---|
| 修长 | 身高约183cm,骨架修长、肩线平直宽阔、锁骨清晰、颈线修长、腰身收窄、腿部修长 |
| 匀称运动型 | 身高约180cm,肩宽腰窄的倒三角廓形,肌肉线条自然紧实(不夸张),前臂线条清晰 |
| 清瘦文艺 | 身高约178cm,骨架纤细、肩线略斜、锁骨明显、手指修长 |
| 健硕 | 胸背宽厚、手臂结实、整体厚重感(仍保持自然,不夸张) |
**不写**:肌肉块数、"爆炸般的肌肉"、夸张的胸围腰围。

## 5. 肤质与光
- 侧光下能看到面部起伏的投影、鼻梁与额头的薄油光、颧骨外侧略干的颗粒感
- 单侧硬光、大光比,只照亮脸的一侧与锁骨/颈线,另一侧沉入阴影
- 手部与前臂在光下的细微汗毛、青筋、指节

## 6. 姿势与眼神
**坐**:椅子前沿身体前倾、手肘撑膝、十指交握;靠椅背一条腿搭在另一条腿上;坐台阶双腿分开手搭膝盖
**站**:靠墙一只脚抵墙、双手插进大衣口袋、一手扶栏杆、侧身回头
**走**:大衣下摆被风带起、边走边整理袖口、单手拎外套搭在肩上
**手部小动作**:拉松领带、扣袖扣、整理衣领、指尖转戒指、撩起额前碎发、点烟(可用不点燃的烟/不写烟也可)、握杯、扶眼镜
**眼神**:垂眼看手 / 越过肩头看镜头 / 从下往上看镜头 / 侧脸望向窗外 / 失焦发呆 / 冷静直视
**重心**:一条腿承重、肩膀略低、头微倾——松弛感来源

## 7. 机位与镜头
- 全身显腿长:镜头在腰部高度、略低角度、七分身到全身
- 肖像:85mm、浅景深、半身
- 街拍:35mm、轻微倾斜、背景有杂物
- 低机位仰拍:显气场(避免窥视感,不写不当视角)
- 近景手部/配饰特写:戒指、腕表、袖口、领口

## 8. 场景与氛围
西装/都市:地下停车场、雨后街道、酒店走廊、写字楼电梯、深夜便利店
文艺:咖啡馆窗边、书店、旧公寓、阳台、画室、图书馆
暗黑:雾夜森林、废弃剧院、石阶、地铁站台
户外:海边步道、山间公路、雪地
加分杂物:领带松在椅背、咖啡杯、充电线、烟灰缸(可省略)、翻开的书

## 9. 负面词
```
年龄:未成年、少年脸、幼态、学生制服
结构:多余手指、手指过细、手指畸形、腿部融合、关节错位、鞋子穿模、多余肢体
质感:塑料皮肤、过度磨皮、偶像脸、AI网红脸、瓷娃娃感、过度锐化下颌、贴图般的胡茬、夸张肌肉、HDR油腻高光、CG渲染
杂项:文字、水印、logo、拼图、多宫格
```
无负面输入口时全部改写成正向陈述(见 `anti-ai-realism.md` 第三节)。

## 10. 完整提示词模板与示例

### 八段式模板(男)
```
**主体:** 竖版4:5,真人时尚摄影。一位明确成年的{年龄}岁{地域气质}男性,{脸型}、{眉眼结构}、{鼻}、{唇},{肤色与印记},{胡须状态},眼神{…}。
**发型:** {长度/发质/分缝},{碎发/湿发/乱发处理}。
**服装:** {外套材质与版型}+{内搭}+{下装}+{穿法:领口/袖口/滑落},{面料质感句式}。
**配饰:** {首饰与腕表,哪只手}+{鞋}。
**动作:** {姿态}、重心在{哪条腿}、{左手}、{右手}、{眼神与头部方向}。
**场景:** {空间}+{3–5个生活痕迹}。
**光线:** {光源方向与冷暖},只照亮{哪里},背景比主体暗2–2.5档,略微欠曝,局部过曝。
**身材 / 镜头:** {身高与廓形},{景别}、占画面{比例}、{焦段}、{机位}。
**质感:** {手机直闪 / 胶片型号},细腻颗粒,画面略软。
```

### 示例1:暗夜摇滚(Saint Laurent感)
```
**主体:** 竖版4:5,真人时尚摄影。一位明确成年的28岁东亚男性,脸型偏长,下颌线条自然偏硬朗但略不对称,眉毛浓而略杂乱,眼型细长内双、眼尾平直,鼻梁挺直、鼻头略圆,唇形平直偏薄,冷白皮,眼下有一层很浅的青影,下颌和上唇有浅青色的胡茬,眼神冷静、略带倦意。
**发型:** 黑色微卷中长发,侧分,几缕碎发落在额前,发梢带着雨后的湿气。
**服装:** 黑色哑光小羊皮短款皮夹克,窄肩修身,皮面有自然褶皱,没有油亮高光;内搭黑色丝质衬衫,领口松开三颗扣,露出锁骨与颈线;黑色修身长裤。皮夹克一侧滑落到手肘。
**配饰:** 颈间一条细银链,右手食指与无名指各戴一枚银戒,左手腕一块简约的黑色皮表带机械表;黑色尖头切尔西靴。
**动作:** 他背靠着潮湿的混凝土墙站着,重心放在左腿,右脚脚跟抵着墙面;右手插在裤袋里,左手抬到领口附近,指尖正在把衬衫领口再松开一点。头微微侧向右边,眼帘半垂,视线越过肩头看向镜头,嘴角平缓。
**场景:** 深夜雨后的地下停车场入口,地面有水渍倒影,墙角有一个旧纸箱,远处荧光灯管发出一点绿白色的光。
**光线:** 冷青白色的荧光从画面左侧斜射进来,只照亮他的脸的一侧、锁骨与左手;另一侧沉入深灰阴影;背景比主体暗两档半;远处一点暖黄的车灯在发梢勾出一圈细边。整体略微欠曝,灯管附近局部过曝。
**身材 / 镜头:** 身高约184cm,骨架修长、肩线平直、锁骨清晰、腰身收窄、腿部修长。七分身,从头顶上方留少量空间到小腿,人物约占画面80%,35mm f/1.4,镜头在腰部高度略低角度平视,构图略微倾斜。
**质感:** CineStill 800T 胶片夜景质感,细腻颗粒,暗部偏青绿,画面略软,像被朋友在雨夜随手抓拍到的一张。
```

### 示例2:安静奢华(The Row感)
```
一位明确成年的30岁男性,长脸,单眼皮眼梢略垂,鼻梁中等高度,唇形自然,暖白皮,下颌有两天没刮的胡茬,眼神安静。驼色羊绒长大衣,内搭奶白色高领羊毛衫,深灰直筒西装裤,黑色乐福鞋,无首饰,只有一块简约的银色腕表。他坐在咖啡馆窗边,左手握着陶瓷杯,右手搭在桌面一本翻开的书上,垂眼看向窗外的雨。阴天散射光从左侧窗进来,照亮脸与手背,背景比主体暗两档,低饱和大地色,Portra 400 胶片质感,85mm浅景深,半身构图。
```
