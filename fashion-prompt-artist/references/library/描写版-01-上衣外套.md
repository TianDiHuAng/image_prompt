# 描写版 01 · 上衣 · 外套（具体描写）

> 每条 = 名词 + 中文具体描写 + 英文描写片段（逗号短语，可直接拼进提示词）。
> **上衣描写公式**：版型廓形 → 领口 → 袖型 → 面料光感 → 穿着状态（塞入/敞开/堆叠），五选三即可成段。
