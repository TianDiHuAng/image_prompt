# 面料、质感与色彩

## 面料(写法:材质 + 表面 + 光泽 + 垂坠/厚度)

| 类型 | 词汇 | 视觉特征 |
|---|---|---|
| 丝绸类 | 真丝双绉 silk crepe / 缎面 satin / 真丝雪纺 / 塔夫绸 taffeta / 丝绒 velvet / 天鹅绒 | 缎面=高光、流水感垂坠;双绉=哑光细纹;塔夫绸=挺括有"沙沙"感;丝绒=吸光、深邃 |
| 轻薄透 | 欧根纱 organza / 网纱 tulle / 蕾丝 lace / 薄纱 chiffon / 雪纺 | 轻盈、半透、层叠 |
| 针织 | 羊绒 cashmere / 马海毛 mohair / 美利奴 merino / 罗纹 rib / 麻花 cable / 针织 jersey / 粗线毛衣 chunky knit | 柔软、毛绒、温暖 |
| 羊毛呢料 | 羊毛双面呢 / 粗花呢 tweed / 法兰绒 / 驼绒 / 山羊绒大衣料 | 厚、挺、层次 |
| 皮革 | 小羊皮 lambskin / 打蜡皮 / 漆皮 patent / 哑光皮 / 麂皮 suede / 做旧皮 | 皮革光泽与褶皱 |
| 金属感 | 金属链甲 / 金箔 / 亮片 sequin / 水晶刺绣 / 珠绣 beaded | 反光、闪烁 |
| 特殊 | 乳胶 latex / 弹力网纱 / 激光切割 / 羽毛 feather / 毛皮 faux fur | 强风格 |
| 日常 | 牛仔 denim / 帆布 / 棉麻 / 弹力棉 | 日常质感 |

## 质感形容词(让面料"可触摸")
- 柔软:buttery soft, brushed, fuzzy halo, cloud-like
- 光泽:liquid satin sheen, mirror-like patent, subtle pearl sheen
- 挺括:crisp, structured, sculptural
- 垂坠:fluid drape, cascading folds, liquid movement
- 粗糙:slubby, nubby, rough-hewn
- 透:sheer, gossamer, translucent layered over opaque lining

## 色彩搭配公式
**主色 60% + 辅色 30% + 点缀 10%**

### 氛围与配色
- 冷峻:炭黑 + 冰灰 + 银色
- 高级克制:燕麦 + 驼 + 象牙
- 浓烈戏剧:正红 + 黑 + 金
- 暗黑浪漫:深酒红 + 黑 + 古铜
- 清冷:雾蓝 + 珍珠白 + 银
- 温柔:奶油白 + 淡粉 + 浅灰
- 复古:焦糖 + 橄榄绿 + 奶油
- 夏日:象牙 + 赤陶 + 天蓝
- 酸性街头:荧光绿/黄 + 黑 + 灰

### 对比技巧
- 同色系层叠(tonal dressing):色阶渐变,显高级
- 黑+一点金/红:冲击力强
- 冷暖对比:冷色衣服+暖色首饰/唇色

## 肤质与光泽(人物渲染)
natural skin texture, soft satin highlights on shoulders and collarbone, dewy skin, subtle sheen, fine pores visible, healthy glow

## v3 提醒:面料的"AI感"风险
- 浅色缎面/丝绸/雪纺 + "垂坠感" = 一眼AI(完美液态高光、零褶皱)。
- 写实模式优先:深色缎面/丝绒(酒红、墨绿、藏蓝、深紫)、罗纹针织、莫代尔、弹力棉、羊毛呢料。
- 必须用浅色缎面时,加:"表面有自然折痕与轻微拉扯纹,无油亮高光"。
- 通用句式:能看到清晰的织纹、自然折痕和轻微起球,表面没有反光也没有油亮的高光。
- 厚涂/插画模式不受此限,缎面高光反而是加分项。
