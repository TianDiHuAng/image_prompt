# 首饰与配饰词汇

> 原则:**最多2–4件,只选一件做焦点**。首饰与领口要"对话":深V配细长项链,一字领配耳环,高领配长链/不戴项链。

## 项链 / 颈饰
- 细金链 delicate gold chain / 锁骨链 / 多层叠戴 layered chains
- 珍珠:单串、多串、巴洛克不规则珍珠、长珍珠链(Chanel式)、珍珠 choker
- 粗链 chunky gold chain(Balenciaga/Bottega式)
- 钻石 / 水晶:河流项链 riviera necklace、水滴吊坠、方形钻石
- 项圈 choker:丝绒带、金属圈、皮革、珍珠、钻石
- 吊坠:长度落在锁骨 / 胸口 / 深V终点,以"引导视线"
- 衣领装饰:丝巾、领结带、丝带

## 耳饰
- 小巧:珍珠耳钉、钻石耳钉
- 长款:水滴 / 流苏 / 瀑布型耳坠 drop earrings / chandelier earrings
- 夸张:大金属圈 hoop、几何金属、艺术雕塑感耳环(Schiaparelli式)
- 单只耳环:不对称戏剧感
- 耳骨夹 ear cuff、多耳洞叠戴

## 手部
- 戒指:金属宽戒、多指叠戴、宝石鸡尾酒戒 cocktail ring、素圈
- 手链 / 手镯:金属宽镯 cuff、细链叠戴、珍珠手链、腕表
- 手套:歌剧长手套(opera gloves)缎面/皮革/蕾丝、短皮手套
- 指甲:裸色、红色、法式、黑色、镜面、短而干净

## 身体链饰
- 腰链 waist chain / 腰带 belt:金属链、皮带、宽腰封 corset belt
- 脚链 anklet
- 背链 back chain(配露背装)
- 胸链 / 肩链 / 手链连戒指 hand harness (保持高级时装感)

## 头部
- 发型:低盘发 chignon、湿发背头 slicked-back、卷发、长直发、披肩、凌乱慵懒卷发、编发、波波头
- 发饰:发夹 barrette、珍珠发夹、丝带、金属发箍、头巾、发网
- 帽子:贝雷帽、宽檐帽、渔夫帽、针织帽
- 面部:红唇、裸唇、烟熏眼妆、眼线上扬、闪粉眼影、湿润妆

## 眼镜
细框墨镜 / 包覆式墨镜 wraparound / 猫眼 / 大方框 / 圆框 / 银色镜面

## 包袋
- 小巧链条包、手拿包 clutch、托特、信封包、半月包、编织包(Bottega式)
- 位置:挎在肘部、夹在腋下、手拎、肩背

## 鞋靴
- 高跟:细跟 stiletto、方头、尖头、凉鞋、绑带高跟、玛丽珍
- 靴:袜靴(Balenciaga式)、过膝长靴、短靴、牛仔靴、机车靴、漆皮靴
- 平底:芭蕾平底、乐福鞋、凉拖
- 袜:丝袜(透/不透)、网袜、短袜、膝袜

## 首饰材质词
18k gold, polished silver, brushed gold, rose gold, oxidized silver, baroque pearls, South Sea pearls, brilliant-cut diamonds, emerald-cut stones, black onyx, jade, sapphire, ruby, tourmaline, crystal embroidery, enamel, resin

## 首饰 × 领口配对速查
| 领口 | 首饰建议 |
|---|---|
| 深V | 细长吊坠项链,终点落在V字尖;或不戴项链,戴耳环 |
| 一字领 / 露肩 | 长耳坠,不戴项链,让锁骨裸露 |
| 挂脖 halter | 不戴项链,用耳环+手镯 |
| 高领 | 长链叠戴、大耳环、不戴项链 |
| 抹胸 | 项链/choker/耳环任选 |
| 露背 | 背链、发型盘起、耳环 |
| 圆领 | 短项链、珍珠串、锁骨链 |
