# 去 AI 感手册(实测结论整合)

> 核心:**"真实"和"好看"可以在中间相遇**。皮肤可以糙,五官不能糙;光可以暗,不能全亮;面料要哑,不要液态高光。

## 目录
1. 三个档位

3. 面料:AI感的最大来源

5. 手机随手拍模块

## 1. 三个档位
| 档位 | 特征 | 原因/做法 |
|---|---|---|
| 太AI | 完美对称、光干净、姿势摆拍、皮肤无瑕 | 默认状态,不加控制就是这样 |
| 太土/偏老 | 真实了但脸塌、表情僵 | 五官缺点写过头,会直接显老 |
| **平衡 ✅** | 有雀斑毛孔,但五官好看 | **皮肤可以糙,五官不能糙** |

✅ 可写:雀斑、眼下淡黑眼圈、脸型左右略不对称、内双、几颗小痣、毛孔、细小绒毛、枕头压痕、微肿眼皮
❌ 不写:牙齿不齐、颧骨过高、眼睑浮肿、塌鼻梁、嘴角下垂(写了会显老显丑)

## 2. 脸与骨相:写结构,不写"漂亮"
"清秀自然的鹅蛋脸/偏大的杏眼/鼻梁挺直鼻头小巧/双唇自然丰满"是大多数美女的共同特征,写了等于没写,模型会收敛到同一张脸。**换种子没用,换描述才有用。**

每次从这五个维度**换一组不同的组合**:
1. 脸型:长脸 / 圆脸 / 小脸尖下巴 / 方圆脸 / 窄长脸
2. 眼:单眼皮细长眼梢上挑 / 内双 / 宽双眼皮大圆眼 / 眼距略宽或略窄
3. 鼻:鼻梁中等高度鼻头圆润 / 鼻尖微翘 / 鼻梁低平小巧
4. 唇:薄唇 / 唇珠明显 / 厚唇 / 唇形平直
5. 肤色与印记:冷白 / 暖白 / 白里透红 + 淡雀斑 / 小痣 / 淡黑眼圈

**批量出图时**:同一角色固定描述(保脸),换服装/场景/光线;**换角色要换描述**,不要只换种子。

## 3. 面料:AI感的最大来源
| 高危 | 原因 |
|---|---|
| 缎面/丝绸/雪纺/"垂坠感" | 完美的"液态高光"+零褶皱垂坠是CG标志 |

不是禁用,而是**换用法**:
- ✅ 深色缎面/丝绒(酒红、墨绿、藏蓝、深紫),反光变成情调光
- ❌ 浅色缎面(象牙白、银灰、玫瑰粉),最易出塑料感
- ✅ 罗纹针织/莫代尔/弹力棉:哑光 + 纵向织纹 + 自带贴合,"又哑光又显身材"
- ❌ 平纹纯棉/棉麻:哑光但没弹力,显臃肿

**关键句式**(写面料时带上):
> 能看到清晰的织纹、自然折痕和轻微起球,表面没有反光也没有油亮的高光

## 4. 光线:写物理现象,不写形容词
| ❌ 空话 | ✅ 物理现象 |
|---|---|
| 氛围感光线、柔和唯美、电影级调色 | 手机直闪打在脸和白墙上,脸边缘有生硬阴影 |
| 影棚柔光、轮廓光 | 逆光把飞舞的碎发照出金色边缘 |
| — | 只照亮脸的一侧与锁骨,另一侧沉入阴影,背景暗2–2.5档 |
| — | 整体略微欠曝,局部过曝 |

**光比越大、留白越多,越不像AI**;全照亮=一览无余=假。

五档光线:
| 档 | 写法 | 适合 |
|---|---|---|
| A 单侧窗光 | 光斜射进来,只照亮脸一侧与锁骨,另一侧沉入柔和阴影 | 高级感,最佳通用 |
| B 床头暖灯 | 夜间一盏暖灯从侧下方打上来,背景暗2.5档 | 最有"味道" |
| C 清晨逆光 | 光从纱帘后透进来,发缘有金色轮廓 | 日系清透 |
| D 阴天散射 | 柔光几乎无硬阴影 | 商业感、看清材质 |
| E 手机直闪 | 硬光、生硬阴影、局部过曝 | 最真实,去AI最强 |

## 5. 手机随手拍模块(最强降AI手段)
比任何"realistic"都管用:
> 手机夜景直闪随手拍,iPhone主摄,ISO 1600高噪点与彩色噪点,轻微手抖造成的模糊,细节略软、不是超清;构图略歪、头顶空间被裁掉一点

配套三件套:
1. **构图不完美**:略歪、裁掉头顶/手肘、人物不完全居中
2. **场景有杂物**:充电线、水杯、纸巾、空调机、塑料水桶
3. **动作有故事**:刚被叫住转身、手里拎着便利店袋子、伞还在滴水

## 6. 胶片与镜头锚点:要具体
- ✅ `CineStill 800T`(夜景港风)、`Kodak Portra 400`(暖调旅拍)、`Fujifilm Pro 400H`(日系清透)
- ✅ `35mm f/1.4`、`50mm f/1.8`、`85mm f/1.4`
- ❌ `Cinematic / film look / movie grade`(只会得到滤镜化的假电影感)

## 7. 去AI味负面词(仅用于**有独立负面输入口**的工作流)
```
塑料皮肤、过度磨皮、完美对称脸、网红脸、整容脸、广告感、HDR、超清4K、影棚布光、电影级过度调色、AI对称脸、假睫毛夸张化、过度锐利的虹膜、蜡像感
```

**硬规则:负面词永远不写进正向正文。**
- 有独立负面输入口(SD/Flux 双输入框、MJ 的 `--no`)→ 填到负面框。
- 只有正向文本框(H3 / Minimax 系等)→ **整段省略**,改为全部正向陈述。
  实测:写"不要插座"墙上真出现插座;写"不是纯黑"暗部反而更多。详见下文 v3.1 第三节。

## 8. 骨相写法示例(通用示范,非"某地人长这样")
> 脸型偏长,眼型细长内双,眼尾略上挑;鼻梁中等高度、鼻头小巧圆润;唇形平直偏薄;冷白皮,鼻梁与颧骨有淡淡雀斑,眼下有极淡的青影

> 小圆脸,婴儿肥,宽双眼皮圆眼,眼距略宽;鼻尖微翘;唇珠明显;暖白皮,左脸一颗小痣

写法要点:**每个器官一个具体结构词**,不堆"美"字;缺陷只放在"皮肤"层面。

## 9. 可选偏好开关(用户指定时才启用,默认关闭)
这些来自个别实验者的个人偏好,不是通用规则:
- **肤色偏好**:要"瓷白/冷白/暖白" → 直接写这些正面词即可(有负面输入口时可另加"深肤色、蜜色、晒黑";只有正向框就不要写)
- **东亚骨相稳定**:模型会把"高鼻梁/深眼窝/轮廓立体"滑向欧美脸。要稳定东亚骨相时,**全部改写成正向结构描述**——"鼻梁中等高度、鼻头小巧圆润、面部柔和、颧骨平缓、眼型细长内双",并把这段放在提示词**最前面**;不写"混血"。只有正向框时不要加任何"避免项"。
- 用户没要求时,不额外限定肤色与种族特征,也不对任何地区做刻板描述。

# v3.1 补充:实战手册要点(轻度采纳)

## 一、AI味的三层来源
模型约占60%、光约占30%、色调与锐度约占10%。提示词能管的主要是"光";在色调/锐度上折腾收益最小。**换模型比改词更有效**,但这属于工具选择,按用户实际使用的模型调整。

### 两类底座的实测差异(同提示词、同种子、同尺寸)

| 指标 | 视频底座(如 H3 / MiniMax 系) | 照片底座(如 Z-Image 系) |
|---|---|---|
| 最暗像素 | **0.000(纯黑)** | **0.012(有底)** |
| 平均饱和度 | 0.62 | 0.37 |
| 锐度(拉普拉斯方差) | 72.7 | 29.3 |
| 暗部<18% 占比 | 12.1% | 5.7% |
| 中间调占比 | 69.6% | 79.9% |
| 色温分离(红绿差σ) | 0.214 | 0.144 |
| 道具/光影还原 | **强** | 弱 |

**为什么视频底座更"调过色"**:训练帧经过编码压缩 → 上线前锐化补偿 → 边缘过锐;为保证时序一致 → 帧被降噪 → 没有真实噪点;片源都调过色 → 高饱和 + 青橙分离 + 压死黑。

### 分工建议(按题材,不是按"谁更强")

| 题材 | 更适合 |
|---|---|
| 卧室/暗调/手机随手拍/生活感 | **照片底座** |
| 水下/时装/复杂道具/精心布景 | **视频底座**(道具还原强,但自带商业感) |
| 快速出草稿 | 小模型(6B 级,10–30 秒) |
| 要极细细节、能接受精修感 | 大模型(19B 级,25–40 秒) |

**关键理解**:大模型不是"不听话",是只在自己熟悉的领域听话。超出经验范围时,它会按"广告该怎么拍"来补——加动作、提亮、补道具。

## 二、光:比"皮肤形容词"更有效的杠杆
- 均匀柔光本身就是塑料感来源:光均匀打满整张脸,任何皮肤都会失去厚度。
- **"毛孔、细腻有质感"这类形容词基本无效**:模型先建立光滑表面,再谈细节。让光去"描出"细节:

| ❌ 无效 | ✅ 有效 |
|---|---|
| 皮肤保留真实毛孔 | 侧光下能看见皮肤起伏的边缘各自带着极细的投影 |
| 皮肤细腻有质感 | 鼻梁和颧骨上有一层很薄的油光,反着细碎、不规则的高光点 |
| — | 颧骨外侧的皮肤偏干,有一点粗糙的颗粒感 |

- 具体写法:
  - 光比:一侧接近过曝、另一侧几乎全黑,只留一点反光勾轮廓
  - 方向:单侧、近距离、硬光(台灯/手机闪/窗缝)
  - 亮度:背景比主体暗2–3档,暗部压向深灰(不压到纯黑)
  - 不完美:鼻尖额头的高光略微溢出、白成一小块
  - 色温不一致:左窗冷光 + 右灯暖光混色

## 三、"不要X"会召唤X(无负面输入口时尤其明显)
只有正向文本框时,写"不要X"约等于强化X(实测:写"不要插座"墙上真出现插座;写"不是纯黑"暗部反而更多)。
**处理方式**:把不要的内容改写成正向,或干脆不提:
| ❌ | ✅ |
|---|---|
| 不要伸出手臂 | 她的双手都放在自己腿上 |
| 不要提亮 | 画面整体曝光偏暗,背景是深灰 |
| 不要微笑 | 她的嘴角平缓 |
| 不要插座 | (什么都不写) |

**与本skill其他规则的衔接**
- **有独立负面输入口**(SD/ComfyUI双输入/MJ的--no):照常使用负面词库。
- **只有正向文本框**:不再把整段负面词"折进正向末尾"(可能适得其反);改为**全部正向陈述**。年龄安全同样用正向锚点:"明确成年的25岁"、"成年女性的成熟五官",而不是写"不要未成年"。
- 姿势冲突项也改正向:不写"不要盘腿",写"右脚收在臀部下方、小腿向后折叠"。

## 四、长度:短比长好
同一题材实测:约560字的七段结构,道具和细节出得全;约1770字的详细版,背景元素大量丢失(注意力预算被摊薄)。
**建议上限约600–700字**(中文)。长了就先删形容词、重复的身材段与反面清单。日式七段(主题/主体/人物·表情/服装·姿势/背景·光线/构图·镜头/质感·风格)在这个长度内最稳。

## 五、族裔/地域锁(可选,用户指定时才启用)
只写"成年女性"时,模型按自己的训练偏好填脸。要稳定某种面部倾向时:
- 放在**最前面**,不要放句子中间(会被整条提示词冲掉)
- **全部用正向陈述**,不写"不要欧美"
- 示例(东亚,仅在用户要求时使用):
```
【前提】画面中的人物是东亚女性:黑色或深棕色的直发,深褐色的眼睛;面部轮廓平缓、颧骨不突出、下颌线条柔和;鼻梁中等高度、鼻头小巧圆润;内双或窄双眼皮,眼型偏长。年龄20多岁,成年。以下所有描述都在这个前提下执行。
```

## 六、分辨率(仅本地部署用户相关)
- 超过模型的"舒适像素量"后,模型不知道怎么用多余像素,反而把主体画小、构图变散(实测某6B模型:2.5MP最佳,3.5MP人物变小)。
- 尺寸通常需为32的倍数;先用1–1.5MP出草稿,再决定是否放大。

## 七、后期(只在模型出图偏"油/锐/艳"时)
顺序:轻微模糊 → 降饱和 → 降色温分离 → 抬黑位 → 加颗粒(最后clamp一次,避免噪点把黑位拉回0)。
参考量级:饱和度×0.82、锐度模糊约0.55px、抬黑位约0.02、颗粒约0.005。
**后期改不了光比结构与暗部形状**,不要指望后期救光;强行抬暗部会发灰发雾。

## 八、无效做法(省得再试)
提示词写"低饱和/暗部不要纯黑"(反效果)· 只换采样器 · 后期强抬暗部 · 句中夹写族裔 · 写"不要X" · 提示词超1500字 · 分辨率超过模型舒适档
