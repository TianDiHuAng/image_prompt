## 1. 防止随机组合失控(C模式必加)
```
随机规则:
1. 每个维度只选一个主要选项,避免一次加入过多事件。
2. 动作与道具必须匹配(捡钥匙需要钥匙和地面空间)。
3. 服装必须符合场景和天气。
4. 前景不能遮挡面部、手部关键动作或主要道具。
5. 同一张图只设一个主要动作和一个次要动作。
6. 每次重新抽取,不继承上一张的事件组合。
7. 固定人物的辨识特征不得随机改变。
8. 输出是单张完整图片,不生成九宫格、拼图或分屏。
```
通用随机池维度:场景 / 时间(清晨、午后、黄昏、深夜、雨后阴天)/ 事件 / 姿态 / 神态 / 服装 / 前景 / 配色。

## 2. 角色卡与锁定句式
```
【角色ID】自定义代号
【年龄设定】明确成年(写具体岁数)
【面部】脸型、眼型、鼻型、唇形、肤色、气质(写结构,见 anti-ai-realism.md)
【发型】发色、长度、分缝、刘海、盘发结构
【不可变识别点】发夹、耳饰、发绳、瞳色、特殊配饰(写形状/颜色/位置)
【服装基准】常用轮廓、主色、材质
【色彩基准】主色、辅助色、点缀色
【禁止变化】不能改变的项
```
锁定句式(正向写法):
> 以下特征是身份识别的固定条件:A、B、C。它们清楚出现在画面中,保持原色与原位置。

(注意:不要写"不能缺失/不得替换"的否定式堆叠;无负面输入口时,改成"必须清楚出现、保持原色"这类正向表述。)

## 3. 单张 / 系列 / 连续动作
- **单张图**:可改姿势、服装、场景,只保留核心身份特征。
- **系列图**:固定面部、发型、发饰、主色和摄影风格,只改事件、姿势、场景。
- **连续动作**:除外观外,还要固定服装、机位、背景和光线方向,避免帧间跳变。
- 关键配饰只在开头提一次容易丢:在人物设定与锁定段**各出现一次**。

## 4. 道具与动作的关系(道具不是装饰)
- 手拿杯子:手指环绕杯身
- 开门:钥匙、门把手、身体方向匹配
- 整理头发:手接近发丝,不悬空
- 倚靠栏杆:手臂或身体与栏杆接触
- 荷塘撑伞:手握伞柄,伞面位置与光线方向一致
- 手撑床面:手掌与床面接触并压出褶皱
选3–6个有叙事功能的物件即可,不要堆满背景。

## 5. 任务专用负面词(按任务选,不要全堆)
| 任务 | 负面词 |
|---|---|
| 生活抓拍 | 商业棚拍、完美摆拍、过度精修、过度锐化、背景虚假、过度电影调色 |
| 清透特写 | 塑料皮肤、过度磨皮、夸张大眼、假睫毛过密、过度丰唇、面部畸变、过曝丢失五官 |
| 复杂姿势 | 多余肢体、手脚数量错误、膝盖融合、关节扭曲、手部悬空、支撑关系错误、脚部穿模 |
| 角色插画 | 角色发型变化、配饰缺失、服装配色变化、角色混合、媒介风格变化、3D渲染、真人照片 |
通用四类(年龄/结构/质感/杂项)见 `prompt-templates.md`。无负面输入口时一律改正向写法。

## 6. 常见问题与修正
| 问题 | 常见原因 | 修正 |
|---|---|---|
| 人物不像指定角色 | 识别点太泛 | 固定发型、发饰、瞳色、代表色,开头与锁定段各写一次 |
| 姿势错误 | 只写"优雅坐姿" | 拆分躯干/头/左右手/左右腿/支撑点/接触关系 |
| 手脚畸形 | 手部动作复杂且遮挡 | 减少动作复杂度,写清手指与物体的接触 |
| 构图裁切 | 没写边界 | 明确从头顶到哪里、哪些部位必须完整 |
| 背景像棚拍 | 缺具体环境物件 | 加3–6个有叙事功能的道具 |
| 画面太像AI | 过度完美 | 加轻微不对称、褶皱、噪点、真实曝光;光比加大 |
| 风格混乱 | 堆叠太多媒介 | 选一个主风格,其余作辅助 |
| 光线不统一 | 光源冲突 | 指定唯一主光源,其他只作补光 |
| 要求互相冲突 | 全身+极近特写 | 先删一个 |
迭代原则:**一次只改一个主要问题**。

## 7. 其他小提醒
- 焦段是风格与透视的描述,模型不一定严格执行;比例/范围更重要时,优先写清构图边界。
- 写作优先级:主题与主体 → 动作与构图 → 环境与光线 → 材质与风格 → 硬约束 → 负面词。
- 姿势灵感可参考 AI Pose Gallery 中文项目:动作参考图提供姿势方向,文字提示词锁定人物、服装、机位、光线。
