# 提示词结构与示例

## 通用结构(英文,适配大多数模型)

```
[画面类型], [人物: 成年/年龄/气质], [造型: 廓形+主件+面料+色彩], [配饰与首饰], [发型妆容], [姿态与表情], [场景], [光线], [镜头与构图], [风格/质感/画质]
```

### 填写示例
```
high fashion editorial photograph, adult woman in her late 20s, cool and confident expression,
oversized black waxed-leather coat with exaggerated shoulders over a body-hugging rib-knit dress,
pointed stocking boots, narrow wraparound sunglasses, thick gold chain necklace,
slicked-back hair, minimal makeup, matte skin with subtle sheen,
standing on a wet city street at night, neon reflections,
low angle, 50mm lens, shallow depth of field,
Balenciaga-inspired avant-garde streetwear, ultra detailed fabric texture, cinematic lighting, 8k
```

## 平台适配
- **Midjourney**:短句+逗号,末尾加参数 `--ar 2:3 --style raw --v 7` ;避免过长。
- **Stable Diffusion / SDXL / Flux**:可用权重 `(silk satin:1.2)`,加负面提示词。
- **即梦 / 可灵 / 国产模型**:直接用中文自然语言描写,按"人物+服装+动作+场景+光线+镜头"顺序,更口语化。
- **Nano Banana / GPT-image 类**:完整自然语言段落,可用"请生成……"句式,强调"成年人"。

## 负面提示词(SD/Flux)
```
nudity, nipples, explicit, child, teen, school uniform, deformed hands, extra fingers, bad anatomy,
blurry, low quality, watermark, text, logo, brand logo, distorted face, plastic skin, overexposed, cropped
```

## 构图与镜头词
- 全身:full-length fashion shot, head-to-toe, runway stance
- 半身:half-length portrait, waist-up
- 特写:beauty close-up of earrings and collarbone(强调首饰与肩颈)
- 背影:back view, looking over shoulder(强调背部设计)
- 角度:low angle(显高大)/ eye level / high angle
- 镜头:35mm 街拍 / 50mm 通用 / 85mm 人像 / 100mm 微距

## 光线词
- 柔和窗光 soft window light(温柔)
- 侧光 side lighting(强调线条)
- 逆光轮廓 rim light(神秘)
- 硬光 hard flash(Balenciaga/时装周直闪感)
- 黄金时刻 golden hour
- 夜景霓虹 neon night
- 影棚 studio softbox / beauty dish

## 中文描写模板(小说/人设)
**公式**:`整体印象 → 主件(剪裁+面料) → 色彩 → 配饰首饰 → 随动作产生的细节 → 一句气质收尾`

**示例**:
> 她身上是一件煤灰色的超大针织开衫,粗粒麻花在肘间堆出浅浅的阴影。只系了中间一颗珍珠扣,衣襟一侧斜斜滑下,露出缎面吊带细细的肩带与一小截锁骨。下身是及踝的黑色丝缎斜裁长裙,走动时像水一样流。耳边一枚细长的银色耳坠,在发丝间若隐若现。她不急不缓,像一个不需要被看见的人,却让人无法不看。

## 微调指令(给用户的快捷选项)
- "更含蓄":加披肩/外套,降低开衩,色调更深
- "更强烈":提高开衩,加深V领/背部开口,加亮面材质与金属首饰
- "更温柔":用针织、奶白/粉色系、柔光
- "更冷峻":黑/灰、皮革、硬光、冷表情
- "更高级":减首饰、统一色系、突出面料质感

# v3 补充:八段式骨架(实测稳定)

顺序固定,前面权重高;每段只管一件事,改一段不影响其他。
```
**主体:** 年龄(明确成年)+ 地域气质 + 骨相结构 + 皮肤
**发型:** 长度 + 发质 + 分缝 + 一缕的处理
**服装:** 面色 + 材质 + 版型 + 覆盖范围
**动作:** 姿态 + 重心 + 手的位置 + 眼神
**场景:** 空间 + 背景元素 + 生活痕迹
**光线:** 光源位置 + 光比 + 只照亮哪里
**身材 / 镜头:** 比例 + 构图 + 焦段
**质感:** 介质 + 颗粒 + 皮肤 + 质感定调(正面表述,如"手机直出原片、未修图")
```
**为什么分段**:指令式模型遇到一大段长句会丢约束。分段后便于只改出问题的那一段。

## 负面词不进正文(硬规则)
**八段式只有八段,没有第九段"避免出现"。** 负面词永远不写进正向正文。

- **有独立负面输入口**(SD/Flux 双输入框、MJ 的 `--no`):负面词库填到那个框里。
- **只有正向文本框**(H3 / Minimax 系等):一律省略,改用正面表述——"双手放在腿上""嘴角平缓""画面整体偏暗",年龄用正向锚点"明确成年的25岁"。

实测依据:只有正向框时写"不要插座",墙上真出现插座;写"不是纯黑",暗部反而更多。详见 `anti-ai-realism.md` 第 7 节与 v3.1 第三节。

## 姿态积木("重心偏移"是松弛感来源)
| 类别 | 句式 |
|---|---|
| 坐 | 一只手撑在身后、上身微微后仰、颈线拉长 |
| 站 | 重心放在一条腿上、另一条腿膝盖微弯、脚尖轻点地 |
| 靠 | 靠墙站着,一条腿屈起、脚跟抵着墙面 |
| 躺 | 侧躺,一只手撑着头,一条腿自然搭在另一条上 |
| 跪 | 跪坐地板,上身挺直,双腿并拢向一侧 |
| 回头 | 侧身站立回望镜头,一只手撩起耳边头发 |

## 眼神(魅力第一来源)
半垂眼看镜头 / 从下往上看镜头 / 视线越过肩头看向镜头 / 指尖轻触下唇 / 失焦片刻后望向镜头 / 侧脸望向窗外

## 身材与镜头
身材段每批都带,但**别过度重复**(重复会把不同的人拉向相似)。用廓形语言:
> 身高约170cm,骨架纤细、肩线平直修长、锁骨清晰、颈线修长、腰肢很细、腿部修长,体脂低但不干瘦

| | 七分身全身 | 上半身中景 |
|---|---|---|
| 身材 | ✅ 显高显瘦 | ⚠️ 吃掉腿长、易显壮 |
| 细节 | 脸较小 | ✅ 五官清晰 |
| 选择 | 要身材用这个 | 要脸用这个 |
> 9:16竖版,七分身全身,从头顶上方少量留白到小腿中部;人物高度约占画面80%;约35mm等效焦距,平视,不裁切头顶

## 场景
好用:卧室床沿 / 落地窗夜景 / 米色沙发角 / 走廊纵深 / 梳妆台 / 阳台 / 厨房吧台 / 书房台灯
翻车提醒:浴室水汽、车内太暗会丢脸部细节,**要补一盏正面光**。
加分杂物:床单褶皱、充电线、随手放的水杯、模糊书架绿植。

## 固定流程
1. 选角色描述(换骨相组合,别每次同一型)
2. 选服装(面料+版型+露肤区)
3. 选场景+光线
4. 选姿态
5. 拼装 → 生成 → 只改出问题的那一段
