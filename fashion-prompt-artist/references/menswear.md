# 男装与男性造型词库

> 男性魅力的设计语言:**剪裁的结构感、面料的触感与质感对比、克制的露(领口、锁骨、前臂、手背)、配饰的点题、冷静或慵懒的眼神**。
> 同样遵守:明确成年、完整覆盖、不写露骨内容、不用真人姓名、不写品牌logo。

## 1. 男性魅力的"露与藏"手法
| 手法 | 句式 |
|---|---|
| 领口 | 白衬衫领口松开两三颗扣,露出锁骨与颈线;V领针织露出锁骨 |
| 前臂 | 袖口半卷到小臂,露出前臂线条、腕骨与手表 |
| 肩线 | 强肩西装、落肩大衣;西装敞开,内搭薄针织或简洁背心(有内搭) |
| 腰线 | 修身收腰、高腰裤、腰带;针织衫下摆微微拉起 |
| 背 | 湿润的衬衫贴合背部肌理(保持衣物完整),或深V背的针织(完整覆盖) |
| 手 | 戒指叠戴、手背青筋与指节、手指轻触领口/袖口/下颌 |
| 对比 | 硬朗西装 + 柔软羊绒;粗针开衫 + 丝质衬衫;皮革 + 针织 |
| "将落未落" | 西装外套滑落一侧肩、大衣半披、衬衫下摆一边未扎进、领带松开 |
**原则**:一套只选一个重点(领口 / 前臂 / 肩线 / 手);其余保持克制。

## 3. 服装品类与剪裁
- **西装**:修身单排扣、双排扣、剑领晚宴西装、落肩宽松西装、无衬里软西装、西装马甲、三件套
- **衬衫**:白衬衫(领口开两三颗扣)、丝质衬衫、半透薄衬衫(有内搭)、牛津纺、法式袖口、立领、古巴领
- **大衣/外套**:驼色羊绒长大衣、双排扣风衣、皮夹克(机车/飞行员/长款皮风衣)、麂皮夹克、羽绒、牛仔夹克、蜡棉夹克、山羊皮短外套
- **针织**:高领毛衣(turtleneck)、V领、圆领、麻花、罗纹、粗棒针、马海毛、针织开衫、针织背心(vest)、针织Polo
- **T恤/上装**:紧身白T、V领T、长袖Henley、条纹长袖、卫衣、拉链连帽衫
- **下装**:西装裤(高腰、直筒、阔腿)、牛仔裤(直筒/修身/做旧)、工装裤、皮裤、运动裤、短裤
- **领口与袖口**:开领、立领、翻领、戗驳领、卷袖、露腕、袖口露出一截衬衫
- **长度**:大衣到膝/到小腿;西装外套到髋骨/过臀;短款夹克到腰

## 4. 针织与叠穿(重点)
**针织开衫(男)公式**:`[长度] + [针法/厚度] + [领型/扣法] + [穿法] + [内搭]`
| 维度 | 词汇 |
|---|---|
| 长度 | 常规 / 过臀 / 长款到大腿 / 超大落肩 |
| 针法 | 粗棒针、麻花、罗纹、华夫格、马海毛、羊绒细针、渐变段染 |
| 领型 | V领、圆领、披肩领、立领、无领 |
| 扣法 | 木扣 / 金属扣 / 皮革扣 / 半扣 / 不系 / 拉链 |
| 穿法 | 半扣露锁骨、一侧滑落肩头、袖口堆在手背、披在肩上、系在腰间 |
| 内搭 | 白T / 丝质衬衫 / 高领打底 / 条纹衬衫 / 光身外穿**仅限有明确覆盖**(写"开衫扣好、完整覆盖前胸") |
**示例**
- *温柔文艺*:燕麦色粗棒针开衫,木扣只系中间一颗,袖口盖住手背,内搭白色圆领T恤。
- *克制知性*:炭灰色羊绒V领针织衫,内搭白衬衫领口露出一圈,深色高腰西装裤。
- *冷感*:黑色高领紧身针织,外披超大黑色羊毛大衣,一侧滑落到手肘。
- *复古*:深绿色马海毛开衫,内搭奶白色丝质衬衫,领口松开。

## 5. 面料与质感
- **哑光优先**:羊毛、羊绒、粗花呢、法兰绒、丝绒(深色)、麂皮、罗纹针织、牛仔
- **皮革**:小羊皮(柔软褶皱)、打蜡皮、机车皮、漆皮(慎用,易塑料感)
- **丝质**:深色丝质衬衫可用,浅色/亮面丝缎慎用(AI塑料感)
- **关键句式**:能看到清晰的织纹、自然折痕、轻微起球,表面没有油亮的高光
- **材质对比**:粗针 vs 细丝 / 皮革 vs 羊绒 / 哑光 vs 一点金属反光

## 6. 配色
- 经典:炭灰 + 白 + 黑
- 大地色:驼 + 燕麦 + 深棕
- 暗黑:黑 + 深酒红 / 墨绿 + 一点金属
- 冷感:雾蓝 + 灰 + 银
- 复古:焦糖 + 橄榄绿 + 奶油
- 夏日:象牙白 + 海军蓝 + 浅卡其
- 点缀:一点深红(领带/围巾/衬衫内衬)
法则:主色60% + 辅色30% + 点缀10%,一套look的主色不超过3个。

## 7. 首饰与配饰
- **项链**:细银链、粗银链、十字架(简约)、狗牌、珍珠项链(中性方向)、皮绳吊坠
- **耳饰**:小耳钉、银色耳圈、单只耳钉、耳骨钉
- **戒指**:银戒、粗戒、多指叠戴、印章戒(signet ring)
- **手腕**:机械腕表(皮表带/金属表带)、银色手链、皮绳手链、粗链手镯
- **其他**:细框眼镜、墨镜、皮带(金属扣)、领带夹、领针、袖扣、围巾、手套、帽子(贝雷帽/棒球帽/毛线帽)
- **原则**:最多3–4件;一件为焦点;戒指与表要写**哪只手**与位置;金属统一(全银或全金)

## 8. 鞋靴
- 皮鞋:牛津鞋、德比鞋、乐福鞋、孟克鞋(写鞋头/材质/光泽)
- 靴:切尔西靴、工装靴、马丁靴、骑士靴、短靴、牛仔靴
- 运动/休闲:低帮运动鞋(无logo)、帆布鞋
- 袜:黑色/灰色羊毛袜、条纹袜、露脚踝设计
- 写清:鞋头(尖/圆/方)、跟高(男靴常见3–5cm)、材质、是否有磨损痕迹

## 9. 中性/雌雄同体方向
- 面部:线条柔和但骨相清晰、眼神安静、唇形自然
- 服装:宽肩西装配飘逸衬衫、丝质上衣 + 阔腿裤、长风衣、针织长开衫
- 首饰:珍珠项链、细银戒、单只耳坠
- 发型:中长发、低束发、微卷、侧分
- 关键词:androgynous, sharp tailoring with soft fabrics, quiet confidence

## 10. 示例造型(组合参考)
**A 暗夜摇滚(Saint Laurent感)**:黑色窄肩短款皮夹克,内搭黑色丝质衬衫开领到胸口上缘,黑色修身长裤,切尔西靴,银色细链与叠戴银戒,乱发,侧光。
**B 安静奢华(The Row感)**:驼色羊绒长大衣,内搭奶白高领羊毛衫,深灰直筒西装裤,黑色乐福鞋,无首饰,仅一块简约腕表,阴天散射光。
**C 浪漫高定(Valentino男装感)**:深炭灰修身西装,内搭白色衬衫领口松开两颗扣,深红色丝巾松系在领口,金色领针,黑色牛津鞋,暖色烛光。
**D 暗黑垂坠(Rick Owens感)**:黑色长款不对称皮外套,黑色紧身针织,长发,银色粗戒,黑色靴,冷青色夜光。
**E 温柔文艺**:燕麦色粗针开衫,内搭白T,浅色牛仔裤,帆布鞋,窗边午后光,慵懒。
**F 冷峻都市(Balenciaga感)**:超大肩线黑色羊毛大衣,内搭黑色高领紧身针织,窄框墨镜,雨后街道,硬闪。
