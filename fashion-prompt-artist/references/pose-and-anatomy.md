# 姿势、机位与人体结构锁定

> 复杂姿势(盘腿、抱腿、坐姿交叠)是生图出错最多的地方。写法:**逐肢体、标左右、写接触点、写"不要什么"**。

## 1. 姿势描写模板(B模式)
```
核心姿势:
- 身体:[坐/躺/站]在[位置],[正对/侧身/背对]镜头,腰背[挺直/微蜷],肩膀放松
- 左腿:[弯曲/伸直/下垂],[脚穿什么,落点]
- 右腿:[……]
- 左手:[搭在哪里/做什么]
- 右手:[……]
- 头部:[朝向、倾斜角度、下巴]
- 视线:[望向镜头/窗外/左下方]
- 重心与接触点:[臀部接触、膝盖压床单、手臂把布料压出凹陷]
- 不遮挡:[脸不被膝盖/手遮挡]
```

## 2. 常用姿势库
**坐**:沙发前沿腰背挺直 / 讲台边缘坐、右腿搭左腿 / 高脚凳双腿交叉 / 床沿一手托腮 / 深坐椅上一条腿搭另一条 / 跪坐:一腿踩地一腿折叠(要写"右脚收在臀下、不落地")
**躺**:仰躺抱膝 / 侧卧手支太阳穴 / 仰卧手臂环绕头部 / 趴着下巴搁在叠起的前臂
**站**:倚窗微侧身 / 倚吧台俯身 / 单脚脱鞋失去平衡 / 回头(背部占画面3/4,脸越过左肩回头)
**手部小动作**:拂过颈侧 / 撩发 / 托腮、指尖贴耳侧 / 拇指拉丝袜边缘 / 双手捂杯 / 拳头半藏在袖子里贴近下巴 / 手搭膝盖

## 3. 机位与构图公式
`[画幅] + [景别] + [机位高度/角度] + [镜头mm] + [人物占比] + [裁切规则] + [前景/背景虚化]`

| 要素 | 写法 |
|---|---|
| 画幅 | 9:16 / 4:5 / 3:4 / 2:3 / 1:1 |
| 景别 | 头肩特写 / 半身 / 膝上 / 全身 / 背影 |
| 机位 | 正前方平视 / 略低于视线 / 斜上方俯拍约45° / 距地45–60cm低机位 / 水面低机位 |
| 镜头 | 26–35mm手机感 / 35mm / 50mm / 85mm |
| 占比 | "人物占画面约65%–75%" "人物占画面约80%" |
| 裁切 | "头顶略微裁切" "腿部在上端截断" "不裁切头顶、肩膀" "脚尖超出画面" |
| 前景 | 护栏、被子角、购物袋、模糊的手、玻璃杯大幅虚化 |

注意:近景+全身互相冲突;写了"全身"就不要再写"极近特写"。

## 4. 人体结构硬性要求(可直接粘贴)
```
人体结构硬性要求:
头部、颈部、肩膀符合真实解剖结构;颈部长度自然。
双手各五根手指,指节与关节清晰。
两条腿完整独立,左右膝盖各一处,膝关节方向正确;脚踝自然收窄,脚背与小腿连接正确。
双脚各一只,完整穿入鞋中,鞋跟垂直、不悬空、不融合。
手臂不穿过腿部;身体无异常折叠。
禁止肢体重复、关节错位、腿部粘连、比例失真。
```

## 5. 姿势专属负面词
- 盘腿/二郎腿/跪坐/双脚着地/右腿前伸/右脚悬空(与目标姿势冲突的姿势写进负面)
- 膝盖融合 / 额外脚掌 / 手臂穿过腿部 / 脚趾畸形 / 脚踝扭曲 / 反向膝盖
- 鞋子穿模 / 悬浮鞋子 / 错误鞋跟 / 丝袜穿模
- 面部被膝盖遮挡

## 6. 腿、鞋、袜的稳定写法
- 袜:写**D数+颜色+覆盖范围**:`15D黑色超薄透肤连裤丝袜,完整包覆双腿并连续覆盖足部` / `40D烟灰色连裤丝袜,织物细密柔软`
- 袜口:`过膝厚棉袜,袜口勒出一圈很浅的软肉` / `大腿袜顶部蕾丝边缘`
- 鞋:`黑色尖头细跟高跟鞋,鞋面简洁,皮革自然反光,双脚完整穿入`
- 腿的视觉焦点:`过膝袜口与毛衣下摆之间露出一段白皙大腿,冷白高光沿小腿落下`
- 若不想露腿:明确写"双腿完全被层层裙裾遮住、不露腿"
