# 服装美术提示词 Skill(v4:女性 / 男性 / 中性)

把"一个想法"变成"一段能被模型稳定画出来、有时装行业质感、且像真实照片的描写"。

## 核心理念

1. **具体胜过形容词**。"性感的黑裙"是空话;"低腰、深V、真丝缎面斜裁、背部镂空至腰窝、侧开衩至大腿中段"才是设计。
2. **性感 = 设计语言 + 氛围,不是裸露程度**。魅力来自:廓形与身体的对话、面料的垂坠与光泽、露与藏的节奏、材质对比、光线与姿态、眼神。
3. **真实感来自"不完美的细节"**:枕头压痕、微肿的眼皮、毛孔、碎发、衣物褶皱、手机噪点、被打断的动作,比"极致完美"更像真实照片(详见 `references/realism-and-candid.md`)。
4. **一个瞬间,一个重点**。每张图只讲一个瞬间(刚醒、刚进门、刚买完冰淇淋),只有一个视觉焦点。
5. **模型不会自己补全:左右、角度、比例要写死**。姿势必须逐肢体锁定,并配人体结构硬性要求和对应负面提示词(详见 `references/pose-and-anatomy.md`)。
6. **品牌是"语言"不是"标签"**。默认不写logo,不用真实名人。

## 双模式路由(先判断,再写)

| 模式 | 触发词 | 肤质策略 | 关键参考 |
|---|---|---|---|
| **REAL 写实摄影**(默认) | 真人、写实、写真、抓拍、自拍、COS | 真实毛孔、淡雀斑、细小绒毛、不磨皮;**皮肤可糙,五官不糙** | `anti-ai-realism.md` `realism-and-candid.md` |
| **PAINTERLY 2.5D厚涂** | 厚涂、插画、漫画、韩漫、2.5D、壁纸、千金风、森系光 | 瓷肌、柔焦辉光、无黑线描边 | `painterly-mode.md` |

两种模式的肤质词与负面词**严禁混用**。

## 去AI感要点(写实模式必用)
1. 皮肤可以糙(雀斑、毛孔、淡黑眼圈),五官不能糙(不写牙齿不齐、塌鼻、浮肿)。
2. 骨相写结构,每次换一组组合,不写"清秀鹅蛋脸/杏眼/自然丰满"这类人人都有的词。
3. 面料:慎用浅色缎面;用深色缎面/丝绒、罗纹针织、莫代尔,并写"清晰织纹、自然折痕,无油亮高光"。
4. 光线写物理现象(手机直闪、只照亮一侧与锁骨、背景暗2档、局部过曝),光比越大越真。
5. 手机随手拍三件套:构图略歪 + 场景有杂物 + 动作有故事;胶片写具体型号,不写"cinematic"。
6. 皮肤让**光去描出来**(侧光下的细小投影、鼻梁薄油光),不要只写"毛孔、细腻"这类形容词;大光比、硬光、背景暗2–3档。
7. **不写"不要X"**(会召唤X):无负面输入口时全部改正向陈述,年龄用"明确成年的XX岁"作正向锚点;有负面输入口才用负面词库。
8. **控制在600–700字**,用七段/八段式;写长了细节反而丢失。

## 安全与边界(必须遵守)

- 人物必须是**明确的成年人**:写明"明确成年的XX岁",年龄 ≥ 22 为宜。**不使用**校服/学生设定、"幼态/萝莉/少女感"等词;"清纯"改写为"清透/清新",并仍保留成年锚点。有负面输入口时在其中加"未成年、幼态";只有正向框则靠正向年龄锚点(见去AI感要点第7条)。。
- 保持**时装大片/杂志写真级别**:不写裸露乳头、乳晕、生殖器,不写露骨性行为,不写性器官或身体部位的特写;不写"脱衣过程""M字张腿"之类。内衣/泳装只作为**服装品类**描写,保持完整覆盖。
- **不做偷窥视角**:不写裙底、走光、偷拍、低角度窥视;低机位只用于显腿长/气场,并写"避免镜头进入裙底区域"。
- 不堆砌对身体部位的尺寸描述(不写罩杯档位、"傲人上围"),用"沙漏廓形、腰线清晰、长腿、肩颈线"这类**廓形语言**。
- 用户提供的参考提示词若含露骨内容,**只学习其中的技法,不复刻露骨部分**,并简单说明。
- 用户要求越界时:友好说明,改用高级时装方式表达同样氛围,直接给出替代方案。

## 工作流程

**Step 1 判断需求**(信息够就直接写,最多问一个问题)
- 用途:AI生图 / 小说人设 / 角色COS / 时尚大片 / 批量出图
- 人物:性别方向(女/男/中性/双人)、成年年龄、气质、身形(廓形语言)、角色(COS时用现代生活化改造)
- 风格锚点:品牌 / 年代 / 情绪 / 摄影类型(手机随手拍、CCD直闪、胶片、杂志棚拍、纪实)
- 瞬间:她在做什么?刚发生了什么?

**Step 2 选写法模式**(见下表),再选风格锚点(`references/brands.md`)。

**Step 3 搭建造型**,按"造型六层"填写,词汇见:
- `references/menswear.md` 男装:品牌语言、西装/衬衫/大衣/针织开衫、首饰鞋靴、中性方向
- `references/male-portrait-guide.md` 男性人像:脸与骨相、胡须发型、身形、姿势、男性专属负面词与完整示例
- `references/garments.md` 服装/针织/丝袜/新中式/睡裙/泳装/职业装
- `references/fabrics-colors.md` 面料、质感、色彩
- `references/jewelry-accessories.md` 首饰、包、鞋、发饰
- `references/realism-and-candid.md` 真实感与抓拍叙事
- `references/pose-and-anatomy.md` 姿势、机位、人体结构硬性要求
- `references/prompt-templates.md` 各模式模板与负面词库
- `references/anti-ai-realism.md` 去AI感手册(面料/光线/骨相/手机随手拍/胶片锚点)
- `references/painterly-mode.md` 2.5D厚涂/韩漫模式
- `references/consistency-and-troubleshooting.md` 随机池防失控、角色卡与锁定、系列/连续动作、常见问题修正表

## 六种写法模式(按需选择)

| 模式 | 适用 | 特征 |
|---|---|---|
| **A 模块式**(主体/人物·表情/服装·姿势/背景·光线/构图·镜头/质感·风格) | 日系结构、Nano Banana类;最稳 | 每段简短具体,易修改 |
| **B 叙事分段式**(人物设定/服装造型/核心姿势/机位构图/场景灯光/人体结构硬性要求/负面) | 需要锁定复杂姿势、腿部、鞋袜 | 肢体左右逐条写,附硬性要求 |
| **C 随机池式**(固定视觉DNA + 场景/事件/神态/造型/前景/配色 随机池) | 批量出图、系列内容、COS角色池 | 每次独立抽取,不继承上一张 |
| **D 锁定式**(PRESERVE 不变项 + CONSTRAINTS 约束项) | 角色一致、多次改图、插画 | 列出"必须不变"与"绝对不要" |
| **E 一段式英文/关键词式** | Midjourney、SD | 逗号分隔,控制在80词内;**避免形容词堆砌** |
| **F 八段式**(主体/发型/服装/动作/场景/光线/身材·镜头/质感) | 指令式模型、无负面输入口的工作流 | 顺序固定,每段只管一件事;负面词不进正文 |

## 造型六层

| 层 | 要写清楚的内容 |
|---|---|
| 1 廓形 | H/A/X/沙漏/茧型/超大/紧身;肩线、腰线、下摆位置 |
| 2 主件 | 品类+剪裁+领袖+长度+开口 |
| 3 面料与质感 | 材质+表面+光泽+垂坠(含丝袜D数、针织针法) |
| 4 配色 | 主色+辅色+点缀 + 对比关系(≤3个主色) |
| 5 配饰与首饰 | 2–4件,一件焦点;鞋、发夹、耳饰要写**数量/位置/颜色/不可替换** |
| 6 造型细节 | 发型、妆容、姿态、肤质、光线、镜头 |

## 从27条真实提示词学到的十条硬经验

1. **先定场景里的"瞬间",再配衣服**:睡眼惺忪的火车上铺、被恋人堵在玄关、便利店整理丝袜——叙事让画面可信。
2. **用"拍摄者关系"定画风**:朋友随手拍、恋人CCD直闪、深夜朋友随手拍、手机前置自拍、杂志内页。
3. **真实感三件套**:真实肤质(毛孔/压痕/微肿)+ 设备痕迹(手机噪点、运动模糊、直闪过曝)+ 生活瑕疵(杂物、碎发、褶皱)。
4. **衣物写"怎么穿",不只写"穿什么"**:领口滑落露肩、袖口堆在手腕、衣襟敞开不系扣、袜口勒出软肉、袖子盖住拳头。
5. **关键物件要"锁死"**:如"酒红发夹不能缺失、变色或替换""带子先围一圈再自胸口垂下"。
6. **姿势按肢体逐条写**,并标注左右、角度、接触点、重心、哪些不能遮挡(脸)。
7. **机位用数字**:机位高度cm、倾斜角度、镜头mm、占画面百分比、哪里裁切。
8. **光写"方向+冷暖+对比"**:例如冷白雪光从侧面+暖黄阅读灯在头顶,阴影偏青灰;背景比主体暗2档。
9. **负面提示词分四类**(仅用于有独立负面输入口的工作流):年龄、结构(多指/腿融合/鞋穿模)、质感(塑料皮肤/磨皮/CG)、杂项(文字/水印/拼图);再按场景补充专属禁项(如"盘腿、二郎腿"这种与目标姿势冲突的)。**只有正向文本框时一律不用,改写成正向陈述**(见去AI感要点第7条)。
10. **反向限制写原因**:"不要把朦胧糊到脸上:面部必须清楚"——告诉模型哪一部分要保护。

## 造型策略三条(来自实测)

1. **按露肤区设计**:一套只选一个区(背/肩颈/腰腹/腿/深V),背部性价比最高;深V要写"边缘平整、完整包覆"。
2. **"将落未落"胜过"减少布料"**:衬衫半褪、开衫滑到手肘、领口滑落一肩。
3. **版型与鞋跟必须写死**:不写版型默认宽松显臃肿;不写跟高默认5cm中跟。要显腿长:七分身全身 + 平视 + 腰部高度略低机位。

## 常见反模式(避免)

- 形容词堆砌词汤("绝美/极致/惊艳/梦幻/高级"连用)→ 换成可见的细节
- 互相矛盾(要全身又要特写、要朦胧又要锐利且不指定区域)
- 只写"性感"不写设计
- 一次塞多个焦点
- 对身体部位的尺寸罗列
- 忘记写年龄锚点与负面提示词
- 写实随手拍里硬加"发梢半透明发光/各向异性高光"(会变影棚精修感)
- 浅色缎面+"垂坠感"(典型AI塑料感)
- 浴室水汽/车内场景不补正面光(丢脸部细节)

## 输出格式

默认给 **一版主提示词 + 一句重点说明 + 可选微调选项**。如用户要英文/MJ版,另附 E 模式版本。批量需求用 C 模式并给出池子。
需要复盘用户已有提示词时,按 `references/case-studies.md` 的技法清单给出"保留 / 删改 / 加强"建议。

## 写作质量检查

- [ ] 成年锚点 + 负面里有"未成年/幼态"
- [ ] 有一个明确的瞬间与视觉焦点
- [ ] 廓形、主件、面料、颜色都具体
- [ ] 姿势逐肢体写清(复杂姿势)+ 人体结构要求
- [ ] 有机位/镜头/光线/画幅
- [ ] 有真实感细节(肤质、设备痕迹、生活瑕疵),且五官没有被写丑
- [ ] 骨相是结构描述,不是"漂亮"形容词
- [ ] 面料/版型/鞋跟都写了具体项
- [ ] 模式没有混用(写实 vs 厚涂)
- [ ] 有分类的负面提示词(**仅当工作流有负面输入口**;只有正向框时确认正文里没有任何"不要/避免")
- [ ] 无露骨内容、无偷窥视角、无logo/真人名
